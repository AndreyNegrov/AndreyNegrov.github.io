## Что надо знать о движке (итог разбора)

- Все скрипты делят одну область имён: повторный `const` верхнего уровня ломает файл. Содержание сезона держать внутри IIFE. Id сцен уникальны на всю игру — префикс `h1-`.
- Сезон отдаёт таблицы `LEGEND, LEGEND_GROUPS, PHRASES, EXPLAIN, CLUES, SUSPECTS, DOSSIER_FIELDS, MISSIONS, CAST, ORDERS, PLANS, FINALE, FLOW`, плюс `people` и `glossary`. Передавать все: пропущенная таблица останется от прошлого сезона. `LEGEND` пустым быть не может: минимум `{ city: LEGEND_CITY, job: { x: { ru, en, short, say, any: [] } } }`.
- `meta`: `id`, `season` (свободно 6), `key` (свой ключ сохранения), `tab`, `kicker`, `title`, `lead`, `cta`, `unit`, `bg`, `look`.
- Сцены кладутся в общий `SCENES`. Тип сцены — функция `async (sc, tok) => null | { fail } | { goto }` в `ENGINES` (`js/main.js`, около строки 579). После каждого `await` проверять `tok.dead`; свои таймеры чистить через `Game.onLeave`.
- Ввод: `ReplyBox(host, opts)` из `js/core.js` даёт кнопку «Говорить» и поле; `wait()` возвращает один ответ. Проверка слов: `matchFact(text, { any | all | test })`, `norm`, `hasPhrase`, `isRussian`, `isQuestion`.
- Звёзды итога (`Mission.stars`): след ниже 50; `MISSIONS[n].goal.test`; не меньше двух фраз из `PHRASES` за миссию (ноль задать нельзя) — значит, `PHRASES` нужны, и в `city` стоит звать `Phrases.detect(text)`.
- Голос: `Voice.sayAsync(text, { who })`, голос берётся из `PEOPLE[who].voice`; реплика обрезается через 12 секунд. Звуки: `Sound.sfx(имя)`.
- Люди без картинки рисуются буквой (`initial`).
